# Stock Portfolio Tracker

## Description

This project is a simple command-line Stock Portfolio Tracker developed using Python. It allows the user to select stocks, enter the quantity of shares, and calculate the total value of the portfolio.

## Features

- Displays available stocks and their prices
- Allows the user to enter a stock symbol
- Allows the user to enter the quantity of shares
- Calculates the value of each stock
- Calculates the total portfolio value
- Validates stock symbols
- Validates the quantity entered
- Allows the user to enter `done` to finish

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- If-else statements
- User input
- Basic calculations
