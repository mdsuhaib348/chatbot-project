# Hangman Game

## Description

This project is a simple command-line Hangman game developed using Python. The player has to guess the hidden word by entering one letter at a time.

## Features

- Randomly selects a word from a list
- Allows the user to guess letters
- Displays the correctly guessed letters
- Tracks incorrect guesses
- Provides a limited number of attempts
- Displays the result when the game ends

## Technologies Used

- Python
- Lists
- Loops
- If-else statements
- User input

## How to Run

Run the following command in the terminal:

```bash
python hangman.py
